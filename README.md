## 🚀 Installation

```bash
# Clone the repository
git clone https://github.com/Allstarjo/Portfolio_v2.git
cd Portfolio_v2

# Open in browser
# Option 1: Double-click on index.html
# Option 2: Use a local server
python -m http.server 8000
# or
npx serve
```

Access at `http://localhost:8000`
